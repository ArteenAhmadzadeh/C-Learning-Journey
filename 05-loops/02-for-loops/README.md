# For Loops

## What I learned

A `for` loop places the initialization, condition, and update of a loop in one statement.

## Example

```c
for (int count = 1; count <= 5; count++)
{
    printf("%d\n", count);
}
```

The three parts are:

1. `int count = 1` — initialization
2. `count <= 5` — condition
3. `count++` — update

## Key concepts

- `for` loop syntax
- Initialization
- Loop conditions
- Incrementing variables
- Repeating a known sequence

## Key takeaway

`for` loops are especially convenient when the loop follows a clear initialization → condition → update pattern.
