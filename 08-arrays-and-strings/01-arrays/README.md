# Arrays

## What I learned

An array stores multiple values of the same data type under one variable name.

## Example

```c
int numbers[] = {10, 20, 30, 40, 50};
```

Each element has an index. C arrays use zero-based indexing:

```text
Index:   0   1   2   3   4
Value:  10  20  30  40  50
```

## Key concepts

- Declaring arrays
- Initializing arrays
- Array indexes
- Accessing individual elements
- Looping through an array
- Finding the number of elements with `sizeof`

## Key takeaway

Arrays allow multiple values of the same type to be stored and processed together.
