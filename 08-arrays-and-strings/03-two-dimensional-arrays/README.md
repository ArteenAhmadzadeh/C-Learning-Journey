# Two-Dimensional Arrays

## What I learned

A two-dimensional array can be thought of as a table made of rows and columns.

## Example

```c
int numbers[3][4];
```

This array contains:

- 3 rows
- 4 columns
- 12 total elements

An element can be accessed using two indexes:

```c
numbers[row][column]
```

## Key concepts

- 2D array declaration
- Rows and columns
- Nested loops
- Accessing `array[row][column]`
- Printing table-like data

## Key takeaway

Two-dimensional arrays are useful for data that naturally fits into rows and columns, such as tables, grids, and later matrix-style problems.
