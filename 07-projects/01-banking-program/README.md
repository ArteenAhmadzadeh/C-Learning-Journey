# Banking Program

## What I learned

This project combines several C concepts into one interactive banking application.

The program provides a simple menu where the user can:

- Check their balance
- Deposit money
- Withdraw money
- Exit the program

## Concepts used

- Variables
- Functions
- Function return values
- `switch`
- `while` loop
- `if` / `else`
- User input
- Logical operators
- Basic input validation

## Program flow

```text
Start
  ↓
Show banking menu
  ↓
User chooses an option
  ├── Check balance
  ├── Deposit
  ├── Withdraw
  └── Exit
  ↓
Return to menu
```

## Key takeaway

A larger program is built by combining smaller concepts into a clear structure. This project is a practical step from individual C exercises toward more complete applications.
