# Rock Paper Scissors

## What I learned

This project combines random numbers, user input, conditionals, and `switch` statements to create a simple Rock Paper Scissors game.

The player chooses:

```text
1 = Rock
2 = Paper
3 = Scissors
```

The computer randomly chooses one of the same three options.

## Concepts used

- Variables
- User input
- `rand()`
- `srand()`
- `time()`
- `switch`
- `if` / `else if` / `else`
- Logical operators
- Comparisons

## Game rules

```text
Rock     beats Scissors
Paper    beats Rock
Scissors beats Paper
```

If both players choose the same option, the result is a tie.

## Key takeaway

This project demonstrates how several smaller C concepts can work together to create an interactive program with real decision-making and randomness.
