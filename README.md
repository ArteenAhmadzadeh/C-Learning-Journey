# Return Values

## What I learned

A function can calculate something and send a value back to the code that called it.

This example contains:

- `add()` returning an `int`
- `average()` returning a `double`

## Key concepts

- The `return` statement
- Function return types
- Passing arguments to functions
- Storing returned values in variables

## Key takeaway

A function does not have to only perform an action. It can also produce a result that another part of the program can use.
