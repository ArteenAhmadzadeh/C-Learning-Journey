# 07 — Larger Projects

This section of my C programming journey moves from small exercises and games into a larger application.

## Project

- **Banking Program** — a menu-driven program that combines concepts learned in the previous sections.

## What this project combines

- Variables
- User input
- `if` statements
- `switch`
- Functions
- Loops
- Logical operators
- Basic program organization

## Folder structure

```text
07-projects/
├── README.md
└── 01-banking-program/
    ├── main.c
    └── README.md
```

## How to compile

Using GCC:

```bash
gcc main.c -o program
```

Run on Linux/macOS:

```bash
./program
```

Run on Windows:

```powershell
.\program.exe
```

## Goal

The goal of this section is to practice combining several previously learned C concepts into one larger, interactive program.
