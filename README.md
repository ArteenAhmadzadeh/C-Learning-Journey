# While Loops

## What I learned

A `while` loop repeatedly executes a block of code as long as its condition is true.

## Example

```c
int count = 1;

while (count <= 5)
{
    printf("%d\n", count);
    count++;
}
```

The loop checks `count <= 5` before each iteration.

## Key concepts

- `while` syntax
- Loop conditions
- Updating a loop variable
- Avoiding infinite loops

## Key takeaway

A `while` loop is useful when repetition should continue as long as a condition remains true.
