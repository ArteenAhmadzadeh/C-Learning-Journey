# Quiz Game

## What I learned

This project combines arrays, strings, loops, user input, and conditional logic into a small quiz program.

The program stores questions and their answers in arrays, asks each question, checks the user's response, and keeps track of the score.

## Concepts used

- Arrays
- Arrays of strings
- Character arrays
- `fgets()`
- `strcmp()`
- `strcspn()`
- `for` loops
- `if` / `else`
- Variables
- User input
- Score counting

## Program flow

```text
Load questions and answers
        ↓
Ask a question
        ↓
Read the user's answer
        ↓
Compare answers
    ↙          ↘
Correct      Incorrect
   ↓              ↓
Increase       Show answer
score
    \            /
       Next question
             ↓
         Show score
```

## Key takeaway

This project demonstrates how arrays and strings can be combined with the control-flow concepts learned earlier to create a more complete interactive program.
