# Functions

## What I learned

Functions let us divide a program into smaller, reusable pieces of code.

In this example, the program uses two functions:

- `greet()` prints a welcome message.
- `print_line()` prints a separator.

## Key concepts

- Creating a function
- Calling a function
- `void` return type
- Function parameters with `void`
- Reusing code

## Key takeaway

Instead of putting everything inside `main()`, functions help organize a program into logical pieces.
