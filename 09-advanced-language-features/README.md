# 09 — Advanced Language Features

This section of my C programming journey introduces several language features for writing shorter expressions and organizing related data.

## Topics

1. **Ternary Operator** — write simple conditional expressions with `?:`.
2. **typedef** — create aliases for existing data types.
3. **Enums** — define named integer constants for a group of related choices.
4. **Structs** — group different pieces of related data into one custom type.
5. **Arrays of Structs** — store multiple structured records in an array.

## Learning progression

```text
Ternary Operator
       ↓
typedef
       ↓
Enums
       ↓
Structs
       ↓
Arrays of Structs
```
